# 🌐 Personal Portfolio Website
A modern and responsive personal portfolio website developed to introduce myself, showcase my projects, technical skills, and career goals. This project also serves as an opportunity to explore AI-assisted web development and improve front-end programming skills.
--
## 📖 Project Overview
The purpose of this project is to build a professional personal portfolio that can be used to:
* Introduce myself and my educational background.
* Showcase personal and academic projects.
* Demonstrate front-end web development skills.
* Create an online portfolio for internship and job applications.
* Practice designing clean and responsive user interfaces.
This project was developed using **HTML, CSS, and JavaScript**, with **Artificial Intelligence (AI)** assisting in interface design, code optimization, debugging, and feature implementation.
---
## 🎯 Objectives
* Build a modern and responsive portfolio website.
* Improve HTML, CSS, and JavaScript skills.
* Learn how to effectively use AI as a software development assistant.
* Practice writing clean, maintainable, and organized code.
* Publish a professional portfolio on GitHub.
---
## ✨ Features
* Responsive design for desktop and mobile devices.
* Smooth scrolling animations (AOS).
* Typing animation (Typed.js).
* Personal introduction section.
* Skills showcase with animated progress bars.
* Featured projects section.
* Contact information and social media links.
* Modern UI with reusable components.
